# Metaphysical Theory Reduction Engine (MTRE)

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Status: Active](https://img.shields.io/badge/Status-Active-brightgreen.svg)](#)

> An interactive computational framework and dashboard that categorizes, analyzes, and dialectically evaluates theories of consciousness and metaphysics using formal logic and nondual reduction.

---

## 📌 Overview

The **Metaphysical Theory Reduction Engine (MTRE)** is an open-source analytical tool designed to bring structure, logical precision, and dialectical reduction to consciousness studies and formal metaphysics. 

By mapping theories onto established philosophical taxonomies and applying formal elimination rules (such as the *Catuṣkoṭi* four-fold negation, Kantian Antinomies, and *reductio ad absurdum*), the engine demonstrates how selective, positive assertions about the fundamental nature of reality resolve into an apophatic or nondual (*Advaita*) metaphysical framework.

---

## 🛠️ Features

- **Taxonomic Mapping:** Classifies user theories according to Robert Lawrence Kuhn’s 10-category landscape of consciousness theories.
- **Dialectical Logic Engine:** Evaluates inputs for explanatory gaps, infinite regresses, circular reasoning, and antinomies.
- **Interactive Visualizations:** Graph and vector representations of ontological commitments and theoretical positioning.
- **Reduction Pipeline:** Demonstrates how competing positive metaphysical claims cancel out under rigorous dialectical scrutiny.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18.0.0 or higher)
- npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/metaphysical-theory-reduction-engine.git
   cd metaphysical-theory-reduction-engine
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Navigate to `http://localhost:3000` to access the dashboard.
